# CoyHouseCalender UI Refresh Design

## 목표

- Material 3 Expressive의 둥근 형태, 넉넉한 여백, 분명한 타이포그래피 위계를 적용한다.
- 커플 앱의 따뜻한 분위기는 seed color에서 파생한 `ColorScheme`의 container 계열로 표현한다.
- 다크 모드, 사용자 seed color, 기존 화면 동작과 데이터 흐름을 그대로 유지한다.
- 월간 달력은 한 화면에 한 달 전체가 보이는 현재 정보 밀도를 유지한다.

## 디자인 시스템

- 색상: 화면의 의미 색상은 `Theme.of(context).colorScheme`만 사용한다. 일정·커플 팔레트처럼 사용자가 선택하거나 데이터에 저장된 색상은 예외로 유지한다.
- 형태: 페이지 카드 20~24dp, 다이얼로그·바텀시트 28dp, 버튼과 칩은 pill 형태를 기본으로 한다.
- 표면: `surface`, `surfaceContainerLow`, `surfaceContainerHigh`를 사용해 계층을 구분하고 낮은 elevation과 얇은 outline을 함께 쓴다.
- 타이포그래피: 화면 제목은 굵고 촘촘하게, 섹션 제목과 보조 문구는 색상·크기로 위계를 나눈다.
- 전환: 기존 월 PageView 전환을 유지하고 FAB 메뉴, 선택 상태, 목록 상태에 짧은 Material 곡선 애니메이션을 적용한다.

## 화면별 설계

- 월간 달력: seed 기반 tonal 헤더, 한국어 요일, 카드형 월 그리드, 선택 날짜 강조, expressive FAB 메뉴, 드래그 핸들이 있는 날짜 상세 시트.
- 일정 작성: 제목 / 날짜·시간 / 알림·반복 / 함께하기 / 꾸미기 / 메모를 카드 섹션으로 재구성한다.
- 일정 상세: 일정 색상과 아이콘이 드러나는 hero 카드, 정보 카드, 메모·후기 카드, 수락·거절 액션을 명확히 분리한다.
- 검색: 상단 검색 필드, filter chip, 카드형 결과와 안내형 빈 상태를 사용한다.
- 리포트: 월 선택 pill, 핵심 건수 hero 카드, 세부 통계 타일, 아이콘·위시 진행 카드로 구성한다.
- 위시리스트: 진행률 요약과 체크 가능한 카드 목록으로 구성한다.
- 설정: 계정/함께 쓰기/맞춤 설정/연동/알림/앱 정보 단위 카드 섹션으로 묶는다.
- 설정 하위 화면: 동일한 카드 목록, 빈 상태, 하단 주요 액션 패턴을 적용한다.

## 비기능 계약

- Firestore 문서, 모델 필드, provider, 라우팅 extra 타입, 알림·동기화 호출을 변경하지 않는다.
- `MonthGrid`의 인접 월 날짜와 일정 `Opacity(0.35)` 및 탭 불가 동작을 유지한다.
- 새 패키지를 추가하지 않는다.
- 기존 `광복절`, 날짜 숫자, `Opacity` 기반 위젯 테스트 계약을 보존한다.
