# 이벤트 색상·이모지 아이콘 설계

2026-07-17 승인. 일정 생성/수정 시 개별 색상 선택 + 이모지 아이콘 지정.

## 데이터 모델

`events` 문서에 `icon: String?` 추가 (이모지 문자열, null/미존재 = 아이콘 없음). `EventModel.icon` + fromMap/toMap/copyWith 반영. 하위호환: 필드 없으면 null.

색상은 기존 `color` 필드 재사용 — 스키마 변경 없음.

## 폼 (event_form_screen)

- **색상 행** (반복 행 아래): 현재 색 원 20px 표시, 탭 → `kCouplePalette` 12색 그리드 다이얼로그 (설정의 색상 다이얼로그와 동일 스타일, 파트너색 비활성 로직은 없음 — 전 색 선택 가능).
  - 새 일정 기본값: 내 커플 색 (couple 스트림에서, 기존 저장 로직과 동일 규칙). 색을 고르면 해당 값으로 override.
  - 수정: 기존 `event.color` 프리필.
- **아이콘 행** (색상 행 아래): 현재 이모지(없으면 "없음") 표시, 탭 → 이모지 프리셋 그리드 다이얼로그 (6열×4행 24개 + "없음" 옵션으로 해제 가능).
- 저장: `color` = 선택값(항상 결정됨), `icon` = 선택 이모지 or null.

## 표시

- **캘린더 그리드 셀(하루짜리)**: 이모지 있으면 색 점 **대신** 이모지(9.5px 라인에 맞춤). 없으면 기존 색 점.
- **멀티데이 바**: 제목 앞에 이모지 prefix ("🎂 제목").
- **일별 리스트(EventListTile)**: 제목 앞 이모지 prefix. leading 색 점은 유지.
- **상세 화면**: 제목 앞 이모지.
- 홈위젯: v2 (비범위).

## 주의 (기존 동작 유지)

- "내 색상 일괄 변경"(설정)은 내가 만든 모든 이벤트 color를 덮음 — 개별 지정 색도 덮임. v1 의도된 동작.

## 에러/엣지

- icon 필드 없는 구 문서 → null 취급, 표시 변화 없음.
- 반복 일정 occurrence 복사본은 copyWith 경유라 icon 자동 보존 확인 필요 (copyWith에 icon 보존 추가).

## 테스트

- copyWith icon 보존 (단위).
- UI는 flutter analyze + Orca 브라우저 E2E.
